# Vagaro vs Jane — note for Carolyn

Carolyn asked how Vagaro or Jane might work with the site. Short guidance for a reply:

## How either would connect

Both platforms host their own online booking. The usual integration with a custom website is:

1. Keep the site’s **Book Now** button (or replace it with “Schedule”).
2. Point that button to her **Vagaro** or **Jane** public booking URL, or embed their booking widget on a simple `/book` page.
3. Retire (or hide) the custom `/booking` flow and admin calendar once she is live on the chosen platform.

No deep API work is required for a first version—just a link or embed.

## Quick comparison

| | **Vagaro** | **Jane** |
|--|------------|----------|
| Best for | Massage, spa, wellness practices | Clinics and allied-health practices |
| Strengths | Familiar spa-style booking, packages, gift cards, retail | Charting, clinical notes, stronger healthcare workflow |
| Site fit | Booking link or embed widget | Online booking link (Jane App) |

## Recommendation

- Choose **Vagaro** if she wants a massage-industry–oriented scheduler with packages/gift cards and a simple client booking experience.
- Choose **Jane** if she wants more clinical charting and documentation alongside booking.

Either works well with this site. Once she has an account and a booking URL, swapping the nav “Book Now” target is a small follow-up.

Until then, the custom booking system on the site remains available via **Book Now**.
